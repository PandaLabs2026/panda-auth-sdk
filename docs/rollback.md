# PandaAuth SDK 回滚说明

## 适用范围

PandaAuth SDK 是按包版本独立发布的 .NET 类库，不是常驻服务；发布与版本承诺见 [SDK README](../README.md)，消费者关系与仓库布局见 [PandaAuth WORKSPACE](../../panda-auth/WORKSPACE.md)。本仓没有生产容器、数据库或服务级部署 pin。

## 消费者侧回退

- 先识别受影响消费者、当前 `PandaAuth.Sdk` 版本及最后一个已验证版本；不要覆写或删除已发布的包/Release 资产。
- 在每个消费者仓把 `PackageReference` 或中央包版本恢复到目标版本；消费者使用 lock 文件时同步恢复 lock 状态。若尚无可用旧版本，先撤回该集成或调用，再修复并发布 SDK。
- 在消费者仓执行其自己的构建、测试和发布流程；依赖版本回退不会自动撤回已经发布的消费者应用，也不会恢复其业务状态。
- 影响多个消费者时逐仓协调兼容版本与发布顺序，不在本仓伪造一个服务级生产回退操作。

## 验收与证据

记录消费者仓、恢复的 SDK 版本/提交、消费者验证结果和发布状态；不得在记录中写入包源凭据或 Token。
